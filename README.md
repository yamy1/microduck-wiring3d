# Microduck 接线图（3D）· 打印耗材

基于 [fanhao375/microduck-replica](https://github.com/fanhao375/microduck-replica) 的 `docs/wiring3d` 改的一版查看器。打印件按 PLA / PETG / TPU 上色，悬停和点击会显示耗材；舵机、电路板、IMU、主控、摄像头、电池和导线保持原样。

打开方式、耗材映射和 GitHub Pages 部署见 [docs/wiring3d/README.md](docs/wiring3d/README.md)。

改耗材只需要编辑 `docs/wiring3d/app.js` 里的 `filamentMap`。

模型与文档的许可沿用上游仓库的 [LICENSE](LICENSE) 和 [NOTICE.md](NOTICE.md)。
